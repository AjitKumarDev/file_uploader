# 📁 File Uploader

A simple and interactive File Uploader project built using **HTML, CSS, and JavaScript DOM concepts**.

This project allows users to upload files and dynamically displays file information such as file name, type, and size.

---

## 🚀 Features

- Upload files using input field
- Display selected file details
- Dynamic DOM manipulation
- Beginner-friendly project
- Clean and responsive UI

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM)

---

## 📚 Concepts Used

- DOM Manipulation
- Event Listeners
- File Input Handling
- Dynamic Content Rendering
